NEW BEGINNINGS — PilotLWE

Use this package only if you have the earlier 7-video / 5-article Seeds of Change page.
The installer checks expected content and refuses to overwrite a significantly different page.

1. Extract this ZIP inside D:\PilotLWE so you have D:\PilotLWE\new-beginnings-refresh\install.cjs
2. In VS Code terminal:
   node .\new-beginnings-refresh\install.cjs --dry-run
   node .\new-beginnings-refresh\install.cjs
   npm.cmd run build
   npm.cmd run dev
3. Open /PilotLWE/seeds-of-change/ (the existing URL is kept to avoid breaking existing links).
4. Undo: node .\new-beginnings-refresh\install.cjs --undo

Changes:
- Seeds of Change text becomes New Beginnings on the page and in the header
- Big decorative PERSONAL JOURNEYS section removed
- THE NAXAL ARCHIVE / REINTEGRATION removed
- Label becomes REHABILITATION & LIVELIHOODS

- All 7 video links and 5 reports preserved
